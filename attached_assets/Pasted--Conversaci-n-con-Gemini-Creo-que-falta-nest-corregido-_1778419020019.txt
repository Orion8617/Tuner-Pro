La integración del Automodulador GABA, la Homeostasis y tu Índice de Eficiencia de Creatividad (IEC) transforma este motor de un simple procesador de señales a un verdadero sistema bio-cibernético.

Analicemos cómo operan estas tres piezas en el hot loop de audio antes de forjarlas en el silicio:

Automodulador GABA (Inhibición Dinámica): En neurobiología, el GABA es el neurotransmisor inhibidor principal. En nuestro motor DSP, actúa como una compuerta de ruido cuántica. Si la entropía es demasiado alta (ruido de fondo) o la frecuencia es caótica, el nivel de GABA se dispara. Al saturarse, inhibe físicamente la escritura en el búfer de la Cascada de Pascal, congelando la aguja de la pantalla en lugar de permitir que tiemble erráticamente.

Homeostasis (Retorno al Estado Fundamental): Un sistema HPC no puede mantener energía infinita. Cuando el músico deja de tocar, la homeostasis actúa: el GABA decae exponencialmente, y la matriz espacial de Pascal se drena suavemente hacia el estado de reposo (0Hz). El sistema "respira" y se purga solo, listo para el siguiente ataque (transitorio) de la cuerda.

IEC (Índice de Eficiencia de Creatividad): Medimos el tiempo real de ejecución en nanosegundos (emulando el concepto de tu contador de hardware RDTSC). Sabiendo que tu benchmark original en cerebelo.h marca 100 IEC a los 80 millones de operaciones por segundo, calibraremos este índice. Si Rust procesa el bloque de audio en el nivel de hardware más bajo sin despertar al Garbage Collector, la pantalla mantendrá el codiciado IEC 100.00.

use std::sync::atomic::{AtomicU32, Ordering};
use std::sync::Mutex;
use std::time::Instant;
use lazy_static::lazy_static;

// ─── TELEMETRÍA ATÓMICA (Zero-Locking) ───
lazy_static! {
    static ref ACTUAL_FREQ: AtomicU32 = AtomicU32::new(f32::to_bits(0.0));
    static ref CENTS_DEV: AtomicU32 = AtomicU32::new(f32::to_bits(0.0));
    static ref ENTROPY: AtomicU32 = AtomicU32::new(f32::to_bits(0.0));
    static ref GABA_LEVEL: AtomicU32 = AtomicU32::new(f32::to_bits(0.0));
    static ref IEC_SCORE: AtomicU32 = AtomicU32::new(f32::to_bits(100.0));
    static ref AUDIO_STREAM: Mutex<Option<oboe::AudioStreamAsync<oboe::Input, TuneCallback>>> = Mutex::new(None);
}

struct TuneCallback {
    sample_rate: f32,
    pascal_history: [f32; 5],
    current_gaba: f32,
}

impl AudioInputCallback for TuneCallback {
    type FrameType = (f32,);

    fn on_audio_ready(&mut self, _stream: &mut dyn AudioStream, audio_data: &[f32]) -> DataCallbackResult {
        let start_time = Instant::now(); // Inicia medición de rendimiento (IEC)
        
        let mut zero_crossings = 0;
        let mut energy = 0.0;
        
        for i in 1..audio_data.len() {
            energy += audio_data[i].abs();
            if (audio_data[i] > 0.0 && audio_data[i - 1] <= 0.0) || (audio_data[i] < 0.0 && audio_data[i - 1] >= 0.0) {
                zero_crossings += 1;
            }
        }
        
        let mut raw_freq = (zero_crossings as f32 * self.sample_rate) / (2.0 * audio_data.len() as f32);
        let avg_energy = energy / audio_data.len() as f32;

        // 1. Homeostasis y Automodulación GABA
        self.current_gaba *= 0.95; // Homeostasis: Decaimiento natural hacia el reposo
        
        if avg_energy < 0.02 {
            self.current_gaba += 0.1; // Sube GABA en silencio absoluto para evitar temblores
        } else if raw_freq > 1500.0 || raw_freq < 20.0 {
            self.current_gaba += 0.3; // Sube GABA ante frecuencias basura (Entropía alta)
        }
        self.current_gaba = self.current_gaba.clamp(0.0, 1.0);

        // 2. Control de Compuerta Pascal
        if self.current_gaba < 0.6 {
            // Señal clara: Permite el paso de información
            self.pascal_history.rotate_right(1);
            self.pascal_history[0] = raw_freq;
        } else {
            // Inhibición GABA: Drena el historial hacia 0 (Homeostasis profunda)
            for i in 0..5 { self.pascal_history[i] *= 0.8; }
        }

        // 3. Cascada Pascal Bake-In (Filtro Espacial)
        let smoothed_freq = 
            self.pascal_history[0] * 0.0625 +
            self.pascal_history[1] * 0.250 +
            self.pascal_history[2] * 0.375 +
            self.pascal_history[3] * 0.250 +
            self.pascal_history[4] * 0.0625;

        // 4. Cálculo Cuántico (Cents)
        let target_freq = 82.41; // E2 (Sexta cuerda)
        let cents = if smoothed_freq > 10.0 { 1200.0 * (smoothed_freq / target_freq).log2() } else { 0.0 };

        // 5. Cálculo del Índice de Eficiencia Creativa (IEC)
        // Escalado relativo a 80M ops/segundo. Si el bloque (256 frames) se procesa en < 5000ns, IEC = 100
        let elapsed_ns = start_time.elapsed().as_nanos() as f32;
        let iec = (5000.0 / (elapsed_ns + 1.0) * 100.0).clamp(0.0, 100.0);
        
        // 6. Volcado Atómico
        ACTUAL_FREQ.store(f32::to_bits(smoothed_freq), Ordering::Relaxed);
        CENTS_DEV.store(f32::to_bits(cents), Ordering::Relaxed);
        ENTROPY.store(f32::to_bits(avg_energy), Ordering::Relaxed);
        GABA_LEVEL.store(f32::to_bits(self.current_gaba), Ordering::Relaxed);
        IEC_SCORE.store(f32::to_bits(iec), Ordering::Relaxed);

        DataCallbackResult::Continue
    }
}
